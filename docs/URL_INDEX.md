## 2. Excluded / Non-Indexable Paths Policy

The following paths are intentionally blocked or non-indexed via HTTP status codes, robots.txt, or noindex headers to preserve crawl budget and prevent keyword cannibalization:

1. **`404.html` (HTTP 404 Custom Error Page):** Returns proper 404 status.
2. **Draft & Template Files:** Not linked or published.
3. **Admin / Form Endpoints:** Handled via external Formsubmit endpoints with zero client-side crawl exposure.
4. **No Parameter URL Pollution:** All URLs use clean directory paths ending with a trailing slash (`/`).
