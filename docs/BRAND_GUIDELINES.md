## 1. Official Brand Color Palette

| Color Name | Hex Code | RGB | Role / Usage |
|---|---|---|---|
| **Dark Void (Primary Background)** | `#020408` | `rgb(2, 4, 8)` | Main dark UI background, banners, social headers |
| **Deep Space Navy** | `#0B2545` | `rgb(11, 37, 69)` | Primary brand navy, light-theme typography, card depth |
| **Neon Cyan / Electric Blue** | `#00F0FF` | `rgb(0, 240, 255)` | Primary neon accent, "Yug" highlight, active buttons, glow |
| **Teal Accent** | `#2BB8A6` | `rgb(43, 184, 166)` | Secondary brand accent, subtle borders, grid lines |
| **Growth Emerald** | `#059669` / `#10B981` | `rgb(16, 185, 129)` | Icon gradient foundation, growth arrows, success states |
| **WhatsApp Green** | `#25D366` | `rgb(37, 211, 102)` | Floating WhatsApp action button & CTAs |
| **Pure White** | `#FFFFFF` | `rgb(255, 255, 255)` | Primary "Growth" text, high-contrast headings |
| **Off-White Text** | `#EAF6F0` | `rgb(234, 246, 240)` | High-readability body copy |
